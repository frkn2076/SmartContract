# SmartContract
A sample block-chain smart contract with Hardhat

## Debugging:
* import "hardhat/console.sol";
* console.log("log message to print on console");
* npx hardhat test

## Local Hardhat node
* npx hardhat node (make node up and running locally)
* npx hardhat ignition deploy ./ignition/modules/Lock.ts --network localhost (interact with the deployed contracts)
